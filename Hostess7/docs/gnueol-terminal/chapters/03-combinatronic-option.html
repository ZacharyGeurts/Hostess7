Combinatronic is optional

The operator may run the combinatronic engine from the same terminal — but never must.

Commands:

  • combinatorics
  • combinatronic
  • g16-combinatronics
  • bash -c combinatorics

These route through Queen/lib/queen-terminal.py → field-compatibility-layers.py status and field-combinatorics-comb.py panel witness. Full studio remains at /compatibility-layers; the terminal only prints posture receipts.

Design conclusion

Compatibility layers replaced operator combinatorics cranks. The terminal respects that: one line of combinatorics output, then you return to normal shell work.

Receipt

pythong Queen/lib/queen-terminal.py dispatch <<< '{"action":"run","command":"combinatorics"}'
