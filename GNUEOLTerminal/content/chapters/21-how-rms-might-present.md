# How Richard Stallman might present GNU terminal work


## Stage presence

*(Grok impersonation)* I would begin at a prompt, not a slide. I would run `emacs`, I would run `gcc`, I would show you the freedom to study the source.

For GNUEOLTerminal I would show: shell ≡ terminal, iron plate JSON, and the combinatoric bridge — then sit down for questions about **license compliance**.
