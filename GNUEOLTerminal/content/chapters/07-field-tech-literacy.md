## Field Technology literacy at the prompt

<span class="tag impl">Implemented</span> Focus: **kitchen metaphor**.

Field Technology sells **addressability**: which binding, which guest offset, which jsonl row, which grep line. When those disagree with a pretty UI, the UI is wrong until stderr reconciles.

Old schoolers: you already knew literacy was power. Field Tech names the writable surfaces so dashboards cannot gaslight you.

The terminal is not a toy shell in a browser tab — it is a **Field Tech instrument** wired to KILROY, Queen, plate meld, and optional combinatronic engines.
