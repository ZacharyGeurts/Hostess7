# MS-DOS 4.0 Module Host

```text
modules
load-module mspaint
load-module edit
mspaint
mem
```

|--------|---------|
| MSPaint | `/mspaint` — PCX · clipboard |
| EDIT | GNU Terminal embed |
| GW-BASIC | coming soon · CHIPS lane |
| MEM | truth witness · memory diagnostic |
