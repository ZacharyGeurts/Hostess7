# The GNU Project — September 27, 1983

Announcement

History On 27 September 1983 Richard Stallman announced the GNU Project: a free Unix-like operating system, developed cooperatively, respecting users' freedom to share and change software.

This chapter is Grok-as-RMS voice for teaching — not a transcript.

Why a terminal book?

Every freedom fight needs a command line. GUIs seduce; shells testify. When you type a command, you declare intent in plain text that can be logged, audited, and shared. Field Technology agrees: addressability beats narrative. Which binding? Which jsonl row? Which allowlist entry?

GNUEOLTerminal (GNU End-of-Line Terminal) is our iron-plated surface: shell ≡ terminal, combinatronic optional, plate meld required.
