## Chapter 1 — Problem

![Collision](h7fig:collision)

authority for local resolve truth where the wartime stack asserts it. Hostess 7 does
not invent block state — she reads boards and files.

## Chapter 2 — Wartime surfaces

![Surfaces](h7fig:surfaces)

- foreign hooks blocked true/false per IP  
- local systemd-resolved stub presence

Status UP vs DEGRADED depends on hooks and services. Pair with global-protector
service matrix for FULL_WAR checks.

## Chapter 3 — Cloud block files

Copilot cloud host blocks are separate null-route lists for known copilot endpoints.
GPT-4 / OpenAI leave-alone policy means those destinations are **not** on the copilot
block list. Different lists, different jobs. Hostess 7 must not merge them in speech.

## Chapter 4 — Angel DNS components

Angel seal status may list DNS-related components (znetwork, field_dns) and overall
SEALED_UP when Hostess component seal + Final Eye are sealed. Multi-doc seal files:
parse the seal event first; trailing control-panel JSON is not a second seal.
