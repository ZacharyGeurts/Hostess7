Shell ≡ Terminal

In this stack, shell and terminal are identical. The same embed serves both:

  • /world/queen-gnu-terminal-embed.html
  • Aliases: terminal, gnu-terminal, shell, gnueol

Queen/lib/queen-field-net.py maps all four names to one URL. The C2 taskbar pin and shell dock both launch the same surface. There is no hidden second shell with broader privileges.

Why one surface

Richard Stallman taught us that ambiguous interfaces hide power. One shell, one allowlist, one API (/api/queen-terminal), one iron plate panel fused into field-plate-meld.py.
